# Cemu Patch Series

Any patches required for upstream `cemu-libretro-android` live in this directory as numbered git patches:
e.g. `0001-description.patch`.

Patches are automatically applied by `scripts/cemu-update-upstream.sh` (or `.ps1`).
Whenever possible, prefer wrapping, configuration, and upstream pull requests over local patching.
Currently, `cemu-libretro-android` requires zero local patches in Omnidroid.
